# Развёртывание (VPS в РФ, Ubuntu 22.04, Docker)

1. Установите Docker и Docker Compose, направьте A-запись домена на сервер.
2. Склонируйте репозиторий, скопируйте `.env.example` в `.env`, задайте: `DB_PASSWORD`, `SITE_URL` (https://домен),
   `SITE_DOMAIN`, `AUTH_SECRET` и `CRON_SECRET` (`openssl rand -hex 32`), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
3. Добавьте в `.env` `ADMIN_EMAIL` и `ADMIN_PASSWORD` (≥10 символов) — первый администратор создаётся при запуске.
4. `docker compose up -d --build` — миграции, начальное наполнение (услуги, этапы, преимущества) и создание администратора
   выполняются автоматически; HTTPS-сертификат Caddy выпускает сам. После входа удалите `ADMIN_PASSWORD` из `.env`.
5. Войдите на `/admin/login`, заполните «Настройки сайта» (название, телефон, мессенджеры, Метрика).
6. Telegram: создайте бота у @BotFather, напишите ему, узнайте chat id, укажите в `.env`.
7. Проверка: `/api/health` → `{"ok":true}`; отправьте тестовую заявку.

Обновление: `git pull && docker compose up -d --build`.
Данные (БД и фото) хранятся в томах `pgdata` и `uploads` и принадлежат заказчику; доступ к серверу, домену и аккаунтам передаётся заказчику.

## Проверьте на сервере при первом запуске
Образ (`docker build`), `docker compose up` и `scripts/backup.sh` разработчик не мог прогнать в своей среде (нет Docker-демона).
Убедитесь: `/api/health` отвечает, заявка сохраняется, отправляется уведомление в Telegram, бэкап создаёт оба файла и восстанавливается.
