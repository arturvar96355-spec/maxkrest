# Спецификация (по ТЗ заказчика)

Реализовано в первом этапе (MVP):

| Раздел ТЗ | Реализация |
|---|---|
| 3. Страницы | `/`, `/uslugi`, `/uslugi/[slug]` (7 услуг), `/kontakty`, `/zayavka`, `/politika-konfidencialnosti` |
| 4. Форма | 4 шага; мультивыбор услуг; динамические поля из `lib/serviceFields.ts`; маска и проверка телефона; согласие; фото до 10 шт. |
| 4.5 Антиспам | honeypot, минимальное время заполнения, лимит по IP, идемпотентный ключ (защита от двойной отправки) |
| 5. Хранение | PostgreSQL (`Lead`, `LeadFile`, `LeadNote`), уникальный номер, статус, дата |
| 5. Telegram | `lib/telegram.ts`; при сбое — статус PENDING, повтор с нарастающей паузой (контейнер `notify-retry` / `/api/cron/retry-notify`), ручная отправка из карточки |
| 6. Админка | `/admin`: список с поиском/фильтром/пагинацией, карточка, 10 статусов, заметки, цена/результат, удаление спама с подтверждением, редактирование настроек, услуг, преимуществ, этапов, отзывов, фото |
| 9. SEO | ЧПУ, metadata, canonical, JSON-LD, `sitemap.xml`, `robots.txt`; Яндекс.Метрика с целями `lead_submit`, `phone_click`, `messenger_click` |
| 10. Безопасность | httpOnly-сессия, bcrypt, лимит попыток входа, заголовки безопасности, HTTPS через Caddy, проверка файлов по сигнатуре, закрытые фото заявок |

## Не входит (по ТЗ п.11)
CRM, онлайн-чат, личный кабинет, оплата, прайс/калькулятор, автогенерация КП.

## Допущения и что нужно от заказчика
- Название, логотип, домен — временные значения, меняются в «Настройки сайта».
- Реальные фото работ и подтверждённые отзывы (отзывы управляются в админке и выводятся на главной только при включённой видимости).
- Токен Telegram-бота и chat id; номер счётчика Метрики; ссылки на мессенджеры.
- Тексты политики ПДн и cookie — шаблон, требует юридического согласования.
- Срок гарантии, условия и стоимость поддержки, периодичность бэкапов (по умолчанию — ежедневно, хранение 14 копий).
- Дизайн-макет главной страницы согласуется отдельно (ТЗ п.7); текущая вёрстка — базовый вариант.
- Автоподсказки адреса — опция после согласования интеграции (не реализовано).
- Одна роль администратора; поле `AdminUser.role` оставлено для будущих ролей.

## Дизайн и структура (обновление)
- Главная: первый экран с быстрой формой «Заказать звонок» (имя + телефон), блоки услуг (иконки), преимуществ, этапов, типов объектов, отзывов (при наличии), контактов и географии.
- Страница услуги: описание, перечень работ, боковая карточка с кнопкой заявки и телефоном, ссылки на другие услуги, JSON-LD `Service`.
- Мобильная версия: меню-«бургер», нижняя панель «Позвонить / Оставить заявку» (кроме страницы заявки).
- Способы связи в форме: мессенджеры показываются, только если ссылки заданы в настройках (в демо-режиме — все).
- Заготовка SEO по районам: `lib/geo.ts` и маршрут `/uslugi/[услуга]/[район]` (пока районов нет — 404).
- Фотографий в дизайне нет намеренно: до получения реальных материалов используются иконки и графика, фото добавляются в админке.

### Анимации и структура главной
Первый экран: поочерёдное появление слов заголовка, лёгкий снегопад, медленно вращающаяся снежинка (параллакс), «сугроб» на стыке секций. Далее: бегущая лента типов объектов, услуги сеткой bento с подсветкой под курсором, тёмная секция преимуществ, этапы с линией, прорисовывающейся при прокрутке, призыв к действию, контакты. Все анимации отключаются при `prefers-reduced-motion`. Цифр и фактов о компании на главной нет намеренно — только подтверждённое заказчиком.

### Название, снег и фоны услуг (по замечаниям заказчика)
- Название: **Royal Snow**; знак-логотип (снежинка под короной) временный, заменяется в «Настройки сайта».
- Падающие снежинки — настоящие снежинки одного цвета в три слоя глубины (на первом экране, в шапках страниц, в блоке призыва); большая вращающаяся снежинка и «шарики» убраны.
- Фон каждой услуги — тёмная векторная сцена в сине-стальной гамме: трактор с отвалом едет по двору (механизированная уборка), самосвал (вывоз), крыша с сосульками, парковка с фонарями, частные дома, офисные башни. Это не фотографии. Если для услуги в админке загружено реальное фото, оно показывается вместо сцены под затемнением.
- Цвет: глубокий тёмно-синий фон, яркий синий (`--color-accent`) только для акцентов и главной кнопки.
- Не добавлены плашки вида «Выезд от 30 минут», «Опытная бригада» — это утверждения, которые должен подтвердить заказчик; после подтверждения их можно внести в блок «Преимущества» в админке.

### Видео первого экрана
- Файлы: `public/hero/hero.webm`, `hero.mp4`, `hero-poster.jpg`. Видео зацикленное (конец плавно переходит в начало), без звука, ~4 секунды; на `prefers-reduced-motion` показывается постер.
- Исходный ролик создан заказчиком в Hailuo AI (по картинке-референсу); ватермарк сервиса обрезан, ролик сжат. Перед запуском проверьте условия использования сервиса и права на материал; когда появятся реальные фото/видео работ — замените файлы в `public/hero/` (те же имена).
- На десктопе видео — фон справа, текст слева; на телефоне — карточка между текстом и формой «Заказать звонок».
