# Инструкция администратора

- **Заявки** (`/admin/zayavki`): поиск по имени, телефону, адресу или номеру; фильтр по статусу. ⚠️ рядом со статусом — Telegram-уведомление не доставлено (заявка при этом сохранена).
- **Карточка заявки**: все данные клиента, фото (просмотр/скачивание), кликабельный телефон, смена статуса, внутренние заметки, согласованная стоимость и результат общения (клиенту не видны), кнопка повторной отправки в Telegram, удаление спама с подтверждением.
- **Услуги**: название, описание, перечень работ, фото, SEO-поля, порядок и видимость; можно добавить новую услугу.
- **Блоки и фото**: преимущества, этапы работы, отзывы (публиковать только подтверждённые), фотографии выполненных работ.
- **Настройки сайта**: название, логотип, телефон, e-mail, мессенджеры, заголовок главной, номер Метрики, Telegram chat id.
